# 历史投资思路总纲：AI 基础设施、国产算力与商业航天

> 版本：v1.0  
> 目标：把本轮对话中形成的长期投资研究框架沉淀为仓库文档，供 GPT、Codex、人工研究者后续复用。  
> 使用原则：这不是买卖建议，而是“研究框架 + 标的池 + 验证清单”。每次更新必须结合最新公告、财报、权威媒体、产业报告重新验证。

## 1. 核心世界观

我们对这一轮长期机会的判断来自两个大方向：

1. **AI 是下一代技术革命**  
   它不是单一软件应用，而是会重塑移动互联网、企业软件、云计算、数据中心、电力基础设施、半导体和工业材料的系统性革命。

2. **商业航天是第二条长期主线**  
   可回收火箭降低发射成本，带动卫星互联网、低轨星座、通信、遥感、军工和地面终端增长。但当前可投标的的利润兑现速度、订单透明度和胜率弱于 AI 基建链，因此商业航天暂时作为长期期权仓。

当前主仓逻辑应以 **AI 基础设施** 为主，商业航天作为低权重长期跟踪。

## 2. 最重要的一句话

不要买“AI 概念”，要买：

> **被 NVIDIA、Google、OpenAI、Meta、Anthropic、AWS、Microsoft、Oracle、CoreWeave 等真实采购链锁定的瓶颈环节。**

进一步升级为：

> **订单硬度决定短期胜率，利润分配决定中期收益，产能瓶颈决定股价弹性，技术演进决定谁可能成为下一代龙头。**

## 3. 研究主框架

所有公司按五个核心维度评估：

### 3.1 订单硬度

判断公司是否直接或间接进入 AI 巨头真实采购链。

证据等级：

- **S 级**：官方公告、双方 IR、SEC 文件、交易所公告明确点名。
- **A 级**：Reuters、Bloomberg、WSJ、Financial Times、TrendForce、LightCounting、Omdia 等主流媒体或产业机构明确确认。
- **B 级**：券商深度、产业链调研、公司单方表述，逻辑强但客户未点名。
- **C 级**：市场传闻、股吧、自媒体、无法核验的研报摘录。

核心原则：

> 未公开点名的客户，不得写成“确定订单”。

例如：
- 中际旭创、新易盛与 NVIDIA/Google AI 光模块链是高置信间接或产业机构验证链，但仍要区分“官方点名”和“产业推断”。
- 麦格米特、英诺赛科出现在 NVIDIA 800VDC 生态中，订单硬度强于泛 AIDC 电源概念。
- 阳光电源不能因为 AIDC 业务布局就写成“有 NVIDIA 订单”。

### 3.2 利润留存能力

重点看：

- 收入增长是否转化为净利润增长；
- 毛利率是否提升；
- 净利率是否提升；
- 经营现金流是否跟上利润；
- 是否有定价权；
- 是否只是收入 passthrough。

典型排序：

```text
NVIDIA / Broadcom / HBM / TSMC / 高端光器件 / 电力设备
>
光模块 / 高端 PCB / CCL / 液冷 / 服务器电源
>
ODM / AI 云 / 普通 IDC / 普通材料
```

### 3.3 产能瓶颈

真正有超额收益的环节往往满足：

```text
需求爆发
+ 供给扩张慢
+ 客户愿意锁产能
+ 良率或认证门槛高
```

重点瓶颈包括：

- GPU / ASIC；
- HBM；
- CoWoS / 先进封装；
- 800G / 1.6T / 3.2T 光模块；
- 激光器、CW 光源、EML、硅光芯片；
- CPO / OCS；
- 800VDC、GaN、SiC、固态变压器；
- 液冷、CDU、冷板、泵阀；
- 高端 PCB、UBB、OAM、交换机板；
- 高密度光纤连接、预端接、空芯/多芯/低损耗光纤；
- 电网接入、变压器、开关设备、燃气轮机。

### 3.4 技术路线位置

当前订单代表现在，技术路线决定未来。

需要重点跟踪的迁移：

```text
GPU → ASIC / TPU / XPU
InfiniBand → Ethernet / Spectrum-X / UALink
800G → 1.6T → 3.2T
Pluggable optics → LPO / CPO / OCS / silicon photonics
48V/54V → 800VDC / HVDC
风冷 → 液冷 → 浸没式
HBM3E → HBM4 / HBM4E
CoWoS → SoIC / 3D packaging / glass substrate
训练为主 → 推理 / Agentic AI
云端 AI → 边缘 AI / 端侧 AI
```

### 3.5 风险扣分

重点扣分项：

- 订单未验证；
- 客户集中；
- 毛利率下滑；
- 存货和应收异常增长；
- 估值透支；
- 大额 capex 和债务；
- 电力接入受限；
- 技术路线被替代；
- 政策和出口限制；
- 传闻驱动但财报不兑现。

投资结论：

应用层空间巨大，但多数应用的商业模式和利润池仍在重构。当前更适合用来判断算力需求，不宜泛买 AI 应用概念股。真正值得关注的是工作流替代强、留存高、付费能力强的应用。

### 4.2 算力芯片层

代表：

- NVIDIA；
- AMD；

## 11. 最终投资哲学

核心哲学：

> **核心仓买胜率，高赔率仓买技术迁移，观察仓买未来可能性。**

不要把传闻当订单。  
不要把收入增长当利润增长。  
不要把短期主题当长期产业趋势。  
不要把“大客户可能相关”写成“大客户确定订单”。

最应该寻找的是：

```text
真实订单
+ 高毛利或毛利改善
+ 产能瓶颈
+ 技术路线正确
+ 财报兑现
```

新的十倍机会更可能出现在：

```text
CPO / OCS / 硅光 / 激光器
800VDC / GaN / SiC / 固态变压器
AI光纤连接材料
AI互连芯片
HBM/先进封装材料设备
国产AI推理算力生态
```
