# AI基础设施投资分析框架

## 中心思想

不要买“AI概念”，要买 AI 扩张过程中的硬瓶颈。

AI 从模型能力竞争，演变为全球基础设施重构：芯片、内存、先进封装、光互联、电力、液冷、数据中心、原材料都被重新定价。

## 五因子模型

1. 订单硬度：是否有NVIDIA、Google、OpenAI、Meta、Anthropic、AWS、Microsoft、Oracle、CoreWeave等真实采购链证据。
2. 利润留存：收入增长是否转化为毛利率、净利率、经营现金流和ROIC。
3. 产能瓶颈：是否存在供给紧张、良率、扩产周期、客户认证或设备约束。
4. 技术路线位置：是否处在下一代架构必经环节。
5. 技术变革受益程度：是否受益于GPU→ASIC、800G→1.6T/3.2T、48V→800VDC、可插拔→CPO/OCS、训练→推理/Agentic AI等迁移。
