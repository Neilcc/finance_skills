# AI Infrastructure Equity Research Framework

## Core idea

Do not buy generic AI concept exposure. Research hard bottlenecks in the AI infrastructure expansion cycle.

## Five-factor model

1. Order hardness
2. Profit capture
3. Capacity bottleneck
4. Technology route position
5. Technology transition upside
6. Valuation and risk

## Current supply-chain map

```text
AI applications / agents / multimodal / long context
→ GPU / ASIC / TPU
→ HBM / CoWoS / advanced packaging
→ NVLink / Ethernet / AI fabric
→ 800G / 1.6T / 3.2T optical interconnect

```

## Research buckets

High-probability core: NVIDIA, Broadcom, TSMC, SK Hynix, Micron, Vertiv, Eaton, Lumentum, Coherent, Innolight, Eoptolink.

High-payoff options: CPO/OCS/silicon photonics, GaN/SiC/800VDC, AI fiber materials, HBM/CoWoS tools/materials, China domestic inference stack.
