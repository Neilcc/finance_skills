# Project投资思路总结

## 目标

建立一个可持续维护、可被GPT和Codex调用的投资研究系统，用于长期跟踪AI基础设施、国产算力、A股/港股/美股产业链和商业航天。

## 核心原则

1. 用产业链判断，不用概念判断。
2. 先找瓶颈，再找公司。
3. 订单硬度优先，传闻只能观察。
4. 利润比收入更重要。
5. 当前订单决定短期胜率，技术迁移决定长期赔率。

## 仓位研究分类

- 核心仓候选：高胜率，财报兑现，订单硬。
- 成长仓候选：高增长，技术方向明确，但估值和客户集中度需跟踪。
- 弹性仓候选：技术路线早期，赔率高但胜率中低。
- 观察仓候选：方向成立，但订单或财报尚未验证。

## 逐步丰富方向

- 建立季度财报摘要库。
- 建立每2–3天滚动更新报告。
- 建立A股/港股/美股证据等级变化日志。
- 建立技术路线时间轴。
- 建立被证伪清单。
